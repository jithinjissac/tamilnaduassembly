## 💡 Key Concepts

### Fresh vs Persistent Browser
- **Fresh:** New browser per large PDF, isolated memory, no crashes
- **Persistent:** Reused browser for small PDFs, fast, always alive

### Fast vs Slow Path
- **Fast:** PDF cached, stream from disk (~50ms)
- **Slow:** PDF not cached, generate on-demand (~11s)

### Background Generation
- Happens automatically after order creation
- Non-blocking (user gets instant response)
- Saves PDF to disk for 30 minutes
- Auto-cleans after expiry

### Error Resilience
- If background generation fails → on-demand generation kicks in
- User always gets their PDF (no 500 error)
- Comprehensive logging for debugging
