Create Order for User

Transfer an admin-created order to a user's account

How This Works

  1. Create Order as Admin: Use the normal "Create Order (Admin)" flow to create an order with all the voter data
  2. Find the Order: Get the Order ID from your admin dashboard
  3. Transfer to User: Use this page to transfer the order to any user
  4. Payment Required: The order will be marked as "pending" - user must complete payment
  5. User Access: Order appears in the user's dashboard where they can pay and download

1 Transfer Existing Order

Tip: First create an order normally (as admin), then use this form to transfer it to a user.
