## 🎯 Key Topics Covered

### System Architecture
- Browser instance management (persistent vs fresh)
- In-memory caching (pdfJobs Map)
- Disk-based caching (public/temp-pdfs/)
- Database integration (MongoDB)
- Cleanup mechanisms

### Workflows
- Order creation → Background PDF → Download
- Preview generation → User feedback
- Payment verification → Access control
- Error handling → Fallback mechanisms
- Auto-cleanup → Disk management

### Decision Points
- Voter count > 1000? → Choose browser type
- PDF cached? → Choose fast vs slow path
- Payment completed? → Allow download?
- Job expired? → Delete from disk?

### Performance
- Small PDFs: ~1 second (persistent browser)
- Large PDFs: ~11 seconds (fresh browser)
- Cached download: ~50 milliseconds
- Auto-cleanup: Every 10 minutes
- Cache lifetime: 30 minutes

### Reliability
- Fresh browser prevents crashes
- Fallback generation if cache missing
- Auto-cleanup prevents disk bloat
- Error logging for debugging
- Graceful degradation on failures
